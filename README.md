# dotfiles

Minimal Catppuccin Mocha macOS setup: SketchyBar, fastfetch, Starship, Neovim, zsh, Terminal.app and Übersicht desktop widgets.

Paste this into Claude Code (or any coding agent) on the new machine:

```text
Set up my macOS desktop rice from https://github.com/thangbuiq/dotfiles-macos.
Clone it to ~/dotfiles (skip if it exists), read AGENTS.md fully, run ./install.sh,
follow the manual steps it prints, adjust the machine-specific values listed in
AGENTS.md for this Mac, then run its Verify commands and report what passed or failed.
Do not commit or push, and ask before overwriting existing config in ~/.config or ~/.zshrc.
```

Widgets are derived from the `.widget` packages of macfetch, github-contributions,
bluetooth-battery-status and theme-controller (restyled).
