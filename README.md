# dotfiles

Minimal Catppuccin Mocha macOS setup: SketchyBar, fastfetch and Übersicht desktop widgets.

```sh
git clone <this-repo> ~/dotfiles && cd ~/dotfiles && ./install.sh
```

AI agents: read `AGENTS.md` first. Widgets are derived from the `.widget` packages of macfetch,
github-contributions, bluetooth-battery-status and theme-controller (restyled).
